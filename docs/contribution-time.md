## 估算方法与局限

- **方法**：按「相邻提交间隔 > 90 分钟视为新工作会话」聚合，累计每段会话的首尾时差（剔除 <10 分钟的碎片会话），再按保守系数折减。
- **局限**：
  1. Git 记录的是提交时刻，不是连续工时；两次提交间可能包含非工作间隔。
  2. 本项目大量实现由 AI 协作完成，负责人主要承担**需求决策、素材提供、文案审核、流程把关**——这部分时间 Git 不记录，但真实存在（已在折减中兼顾）。
  3. 会话切分阈值、折减系数均为人为假设，换参数结果会浮动。
- **建议**：作为志愿时长统计，取中间值 **10 小时** 较为稳妥；如需最保守，可取 **8 小时**。
