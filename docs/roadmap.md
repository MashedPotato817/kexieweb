## 二、已评估、暂缓或不做（防止反复讨论）

| 方案 | 结论 | 理由与重启条件 |
| --- | --- | --- |
| 数据 JSON 化 + fetch 渲染 | **暂不做** | ① `file://` 双击预览会因浏览器安全限制失效（README 承诺的零门槛预览报废）；② 页面内容将依赖 JS 才能显示，失去无脚本兜底；③ 当前仅 4 个部门卡片，数据量小收益低。**重启条件**：活动/项目卡片 ≥ 10 张，或出现「宣发同学网页端直接编辑数据」的真实需求（届时须设计 JSON 加载失败回退 HTML 的降级）。 |
| 群号一键复制 + Toast | **不需要** | 现有群号链接已直达 QQ 加群页，路径更短。 |
| 「改动须通过模块化脚本扩展」写入规范 | **不采纳** | 与「无构建、双击即开」的项目定位冲突。 |
| AGENTS.md 新增 Code Review/Safety Rules 章节 | **不采纳** | 现有机制（保护清单 + 边界检查 + 事实登记 + 人审合并）已覆盖同等约束。 |
| 治理层去 AI 依赖精简（2026-08-24） | **部分采纳** | 仅做 markdown 层：README 瘦身归位、CONTRIBUTING 加降级维护指南与手动步骤清单、skill 加给人看的摘要。检查脚本与 CI 数量不动（保留 4 项检查）。JSON 化维持不采纳（理由见上表「数据 JSON 化」）。
