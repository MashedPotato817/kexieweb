# docs 目录说明

本目录存放网站的文档。按用途分为以下部分。

## 文档索引

- `roadmap.md`：后续工作计划（待办、已评估方案、可选优化），作为 PR 选题依据。
- `architecture-review.md`：前端架构审计与 Vue/TS/Vite 迁移评估结论（保持原生架构）。
- `kexie-mes/README.md`：科协组织信息的「事实登记处」——页面新增/修改的事实性内容必须先在此登记，供校验脚本核对出处。

## 使用规则

- 事实先登记：页面上的日期、群号、联系方式、链接等，先写入 `kexie-mes/README.md`，并在 PR 描述注明来源。
- `roadmap.md` 每完成一项标为已完成并附 PR 编号；新增事项按同样格式追加。
- 本目录内容**不会随 GitHub Pages 发布**（部署仅站点文件）。
