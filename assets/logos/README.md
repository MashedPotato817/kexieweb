# 科协征集

`assets/logos/` 文件夹用于存放科协征集的 logo 图片。

## 命名规则

征集 logo 的图片文件名为 `<作者学号><作者姓名>.<文件扩展名>`，例如 `20231234张三.png`。

## 投稿说明

有意愿参与的同学请将作品发给自己所在部门的部长。所有参与的同学均给予志愿时长，最终采纳的同学给予双倍。

## 与 assets/images 的分工

- `assets/logos/`：征集投稿的暂存区，存放原始投稿作品。
- `assets/images/`：网站发布使用的图片（如最终选中的 logo）。

## gitignore

为了保护作者权益，`assets/logos/` 文件夹下的图片文件已被加入 `.gitignore`，不会被提交到仓库，也不会随 GitHub Pages 公开发布。`README.md` 例外，用于说明本目录用途。

## 发布流程

征集结束后，由负责人将最终选中的作品复制到 `assets/images/` 并提交，中选 logo 才会随网站发布。
